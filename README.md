# 本地相册

在 Windows 上浏览、整理 iPhone 实况照片（HEIC + MOV 配对）的本地网页相册。
照片原样躺在文件夹里，程序只负责看和整理；原片永远不会被修改，转码结果都在 `缓存/` 里。

## 功能

- 相册墙：每个文件夹一个相册，可自定义封面（从相册里挑一张 / 额外上传一张，上传的不会混进相册）
- 全部照片：跨相册时间轴，按拍摄日期分组
- 实况照片：HEIC 自动转码缓存（只转一次），点开可静音循环播放配对视频
- 独立视频：和照片混排在网格里，点开直接播放
- 整理：勾选 → 移动 / 删除（进「回收站」文件夹，可找回）/ 导出到桌面
- 导出回手机：导出时自动补写实况配对 UUID（ContentIdentifier），配合爱思助手「导入实况照片」可导回 iPhone
- 导入：一刻相册下载的 zip（套娃包也行）丢进「待导入」文件夹，网页一键拆包进相册
- 信息面板：拍摄时间、尺寸、拍摄设备、配对视频

## 用法

1. 装依赖（只装一次）：

   ```
   pip install flask pillow pillow-heif
   ```

2. 启动：

   ```
   python app.py
   ```

   或双击 `启动相册.bat`。浏览器会自动打开 http://127.0.0.1:8000

照片放哪（按优先级）：

- 程序上上级目录的「照片」文件夹（适合放移动硬盘，整个文件夹拷走即用）
- 程序目录下的「照片」文件夹
- 都不满意就直接改 `app.py` 里的 `PHOTO_DIR`

可选：把 `ffmpeg.exe` 放到 `app.py` 旁边（[ffmpeg.org](https://ffmpeg.org) 下载），
用于视频缩略图截帧和导出时补写实况 UUID。没有也能跑，只是这两项功能不可用。

## 照片怎么组织

- 照片文件夹里建子文件夹 = 相册（比如 `毕业旅行/`）
- 直接放在根目录的照片归到「未分类」
- 实况照片要求照片和视频同名（忽略大小写），比如 `IMG_0001.HEIC` + `IMG_0001.MOV`

## 从 iPhone 备份照片

1. iPhone 设置 → 照片 → 最底部「传输到 MAC 或 PC」→ 选「保留原片」
2. 数据线插电脑 → 资源管理器 → Apple iPhone → 内部存储 → DCIM
3. 把里面的文件夹直接复制到照片文件夹里

导回 iPhone：整理模式勾选 → 导出到桌面 → 用爱思助手「导入实况照片」。

## 文件说明

| 文件 | 作用 |
| --- | --- |
| `app.py` | 主程序（改照片路径在这里） |
| `scanner.py` | 扫描、实况配对、按日期分组 |
| `templates/` | 网页模板 |
| `启动相册.bat` | 双击启动（Windows） |
| `缓存/` | 转码缓存（自动生成，可删，删了会重新转） |
