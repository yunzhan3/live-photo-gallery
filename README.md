# 本地相册（移动硬盘/win电脑备份管理照片）

在电脑（Windows）上浏览、整理照片的本地小相册，支持普通照片、实况照片（Live Photo）以及录制的视频。
原片存储在文件夹中，转码结果额外存在 `缓存/`文件夹中，两者互不干扰。无需联网、注册。

## 第一次使用（只做一次）

### 方式一：绿色版（推荐，什么都不用装）

1. 在本页面的 **Releases** 里下载 `相册程序_绿色版.zip`
2. 解压到任意位置（移动硬盘也行），得到「相册程序」文件夹
3. 双击里面的 **「启动相册.bat」** → 浏览器自动打开相册页面
4. 想要快捷方式图标：右键 **「重建快捷方式.ps1」** → 使用 PowerShell 运行，
   会在程序上一级生成带图标的快捷方式（移动硬盘盘符变了就再运行一次）

### 方式二：源码版

「Code」→「Download ZIP」或 clone 本仓库，然后：

```
pip install flask pillow pillow-heif
python app.py
```

浏览器打开 <http://127.0.0.1:8000> 。依赖装进电脑的 Python 环境，换电脑要重装。

## 以后每次使用

双击 **「启动相册.bat」** → 浏览器会自动打开相册页面。
用完把黑窗口关掉就行。

## 照片放哪

在硬盘中建一个叫 **「照片」** 的文件夹，把照片放进去：

* 想分相册，就在「照片」里再建子文件夹（比如 `毕业旅行`、`宿舍日常`），一个子文件夹 = 一个相册

* 直接放「照片」根目录的归到「未分类」

* **实况照片**：照片和视频要同名（不分大小写），比如 `IMG_0001.HEIC` + `IMG_0001.MOV`

## 从 iPhone 备份照片

1. iPhone连接硬盘（如果你的硬盘支持的话），进入相册，勾选所需照片，选择共享，选择导出原片，然后选择所需的文件夹。（如果硬盘不支持直接连接iPhone或者是打算把照片备份到电脑，请自行寻找方法导出原片，要点是必须得到静态照片和所对应的视频，不然实况会丢失）（iPad同理）

## 功能一览

| 功能   | 怎么用                                                                                |
| ---- | ---------------------------------------------------------------------------------- |
| 看照片  | 点开相册，点任意照片看大图，键盘 ← → 翻页，Esc 关闭                                                     |
| 播实况  | 打开实况照片的大图 → 底部「▶ 播放实况」（静音循环）                                                       |
| 看视频  | 视频和照片混排在网格里，点开直接播放（有声音）                                                            |
| 写备注  | 大图 → 右下角「ⓘ 信息」→ 双击「备注」那一行，回车保存，点别处取消                                               |
| 整理照片 | 右上角「☑ 整理照片」→ 勾选 → 底部选「移动 / 删除 / 导出」                                                |
| 删除   | 删除的照片挪到「回收站」文件夹（程序自动创建），想找回随时能找回，真正删除需要使用者进入回收站文件夹手动删除。         |
| 设封面  | 相册墙把鼠标移到相册卡片上 → 「🖼 封面」可以额外上传一张照片作为封面；或在该文件夹中整理模式勾选一张 →「设为封面」，此照片将成为该相册的封面         |
| 导回手机 | 整理模式勾选 → 「导出到桌面」（将获得文件夹）→ 用爱思助手「导入实况照片」（将文件夹拖入）导回 iPhone（iphone需要与电脑相连，并且需要提前下好爱思） |
| 批量导入 | 把照片 zip 压缩包放进「照片\待导入」文件夹 → 相册墙底部「开始导入」（这边可以选择导入的位置）                                |

## 这两个文件夹的区别（重要）

* **`缓存/`**：转码产物，**可以随便删**，删了会自动重新生成

* **`照片/相册数据/`**：你的备注和封面设置都在里面，**千万别删**

## 出问题怎么办

* **黑窗口提示"端口被占用"**：相册已经在运行了，直接打开浏览器访问
  <http://127.0.0.1:8000> ；或者找到另一个黑窗口关掉再启动

* **双击 bat 闪退 / 提示找不到 python**（仅源码版）：Python 没装好，重装一下

* **视频缩略图是灰色三角**：缺少 ffmpeg（见下面「可选」），不影响浏览照片

## 可选：ffmpeg（视频缩略图和实况修复用）

没有它也能正常用，只是视频缩略图显示灰色占位图、导出时不能补写实况配对信息。
想要的话：

1. 打开 <https://ffmpeg.org/download.html> ，下载 Windows 版压缩包
2. 解压，把里面的 `ffmpeg.exe` 复制到相册文件夹（和 `app.py` 放一起）
